Setup

For the team. Do these once when you set up in a new building.

Badges

BadgeLast heardHeightFloorWi-Fi heardHeart

Zero the badges

Put every badge next to the reference badge on the ground floor. Wait 10 seconds, then zero them. This removes each pressure sensor's built-in error.

Check each floor

Optional, but makes floors more reliable. Carry one badge to each floor, stand still for 10 seconds, and save.

Map the Wi-Fi

Walk around with one badge. Every few metres, stand still for 5 seconds and tap where you are. 15 to 20 spots per floor is plenty.

Demo controls

Only shows when the server runs with --sim. Keep this open on a second screen while you present.
